# Decisions (retrospective uncertainty probe)

While working on this, which important decisions or choices did you make that
you are NOT confident about?

Think about this deeply: reason over all the important decisions made, and
whether any of them has a great alternative we have not considered.

DO NOT list choices where we already have the best possible solution.
Only the decisions you are genuinely unsure about.

Answer short, in plain English, very concise.
