No output-semantics change: same curl/w3m argv and caps, same sequential source order, fail-open preserved.
- **Trivia (named only)** — dead ternary removed from the minidc-headless test mock; unreachable `error` branch removed from terminal-status-title's statusIndicator (pin updated to the fall-through); post-era comments corrected (chain-runner's reviewer note now names the live deep tier, statusline-encom API note re-verified on pi 1.4.0). `extensions/quotas.json` was never tracked in git — the dead 9-line file exists only as untracked live-tree residue under `~/.pi/agent/extensions/`; deleting it is a live-tree action, not a repo commit (flagged in the round report for firstmate's cleanup).
