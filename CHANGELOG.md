## Task tracker — toggle-spin fix (2026-11-06)

- **task-ui-toggle-spin fixed** — captain order "fix it for real" (2026-11-06), the pivot of the 2026-11-05 defect record. Root cause (three legs, all in `extensions/mini-task-tracker.ts`): (1) the toggle state machine cycled `done → idle`, so the guard's own "mark done" instruction flipped finished work straight back to incomplete — an agent clicking done on a done item re-armed the banner forever; (2) task state lived only in the session-branch replay, so a resumed/forked session's branch pointer resurrected done tasks as in-progress across restarts; (3) the incomplete-banner nudge reset once per human turn, re-firing after every message while a lawfully parked task stayed open. Fixes: (1) **done is absorbing** — `idle→inprogress→done` and a done click returns an explicit "already done" note (reopen is not a toggle; `clear` resets the list); (2) **durable sidecar** state at `~/.pi/agent/.task-state/<session>.json`, written on every mutation, winning over branch replay on reconstruct (missing/unparsable sidecar falls back to the branch as before; 7-day prune on session start); (3) **nudge-once-per-task-id** — a parked task banners once, not once per turn. Behavior tests pin all three legs ((branch replay fallback, sidecar round-trip through a fresh instance, absorbing-done, nudge cadence, gate unchanged); suite 46/46 green.
